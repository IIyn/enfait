enfait est un logiciel de montage vidéo pour ordinateur. Vous enregistrez ou importez votre voix ; enfait nettoie les prises, découpe le texte en blocs, et des animateurs IA construisent chaque bloc en HTML, CSS et SVG. Le rendu se fait image par image, puis tout est monté sur votre voix. Le logiciel tourne sur votre machine.

Étapes d’un projet

Seules les étapes utiles selon le point de départ s’affichent : un texte, une voix off ou une prise filmée.

  1. F5

    Texte

    Vous écrivez le texte. Un prompteur (F5) vous le lit.

  2. REC

    Voix

    Micro, caméra et micro, ou import d’une voix off ou d’une prise filmée.

  3. whisper

    Coupe

    Transcription locale avec whisper. Faux départs, bégaiements et reprises sont repérés ; la dernière prise complète de chaque phrase est gardée.

  4. 2–10 s

    Storyboard

    Le montage est découpé en blocs de 2 à 10 secondes. Pour chaque bloc : un type et une description de ce qu’on voit.

  5. HTML·SVG

    Montage

    Une passe de direction fixe la direction artistique, puis les animateurs créent les blocs en parallèle, les vérifient et les corrigent.

  6. v2

    Retouches

    Notes à la tête de lecture, nouvelle version, ou retour à une version précédente sans rappeler de modèle.

  7. −14 LUFS

    Finition

    Musique, bruitages, ducking. Export MP4 normalisé à −14 LUFS, ou XML FCP7 pour Premiere Pro et DaVinci Resolve.

Le mode magique enchaîne tout à partir d’un seul fichier : nettoyage, storyboard écrit, plans et sons de banques libres, animations, transitions et export.

Types de bloc

Animation
Motion design plein écran.
Mixte
La personne filmée, avec une animation à côté ou par-dessus. Elle peut être détourée pour que l’animation passe derrière elle.
Rush
La prise telle quelle.
Effet
Un effet appliqué à la prise : recadrage, écran partagé, sous-titres…
Plan d’illustration
Un vrai plan tiré de votre bibliothèque ou de banques libres : Pexels, Pixabay, Wikimedia Commons, Openverse.

Un bloc se coupe sur un mot ou se fusionne avec le suivant, et un moment précis peut être ancré sur un mot. Un style global (règles, préréglages, post-FX, polices, fichiers de la bibliothèque) s’applique à tous les blocs et se réutilise dans d’autres projets.

Formats
16:9, vertical 9:16 (Shorts, Reels, TikTok) et carré.
Niveaux de soin
Léger (Haiku), Rapide (Sonnet), Soigné et Ultra (Opus, avec plus de passes de critique sur les images rendues).

Ce qui tourne où

Sur votre machine

Transcription (whisper), coupe, rendu des animations (Chromium headless), mixage et export (ffmpeg). Vos fichiers restent chez vous.

Modèles, au choix

  • une clé API Anthropic, rangée dans le trousseau du système
  • Claude Code installé et connecté, qui utilise votre compte Claude
  • un modèle local derrière une API compatible OpenAI

Sans interface

enfait-cli fait tourner le même moteur en ligne de commande. enfait-cli mcp donne à Claude Code, ou à tout client MCP, l’accès au projet ouvert dans l’application.
